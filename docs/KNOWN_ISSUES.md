## 🔴 Критические

| ID | Проблема | Последствия | Решение |
|----|----------|-------------|---------|
| I-004 | **Нет авторизации (RBAC)** | Поле `role` в таблице users не используется. Все пользователи имеют полный доступ. | Добавить middleware проверки ролей. Разделить admin/user права. |

---

## 🟡 Средние

| ID | Проблема | Последствия | Решение |
|----|----------|-------------|---------|
| I-013 | **Нет CSRF защиты** | POST/PUT/DELETE запросы без токена. Когда auth будет реализован — уязвим. | Добавить CSRF-токены или использовать JWT в Authorization header (Bearer). |

---

## 🟢 Незначительные

| ID | Проблема | Последствия | Решение |
|----|----------|-------------|---------|
| I-018 | **Нет Docker конфигурации** | Нет Dockerfile или docker-compose.yml для удобного deploy. | Создать `Dockerfile` + `docker-compose.yml`. |
| I-019 | **Нет тестов** | Нет unit, e2e или integration тестов. Изменения могут сломать функциональность. | Написать Jest/Supertest для API, Playwright для frontend. |
