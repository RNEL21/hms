## Как заполнять

Добавляйте записи в этот файл при каждом значимом изменении.

### Формат

```
## [X.Y.Z] - YYYY-MM-DD

### Added
- Описание новой функциональности

### Changed
- Что изменилось в существующей функции

### Fixed
- Что исправлено

### Removed
- Что удалено

### Security
- Исправления безопасности
```

---

## Категории

| Категория | Описание | Пример |
|-----------|----------|--------|
| **Added** | Новые функции, эндпоинты, страницы | `Added: POST /api/bookings/create` |
| **Changed** | Изменения существующей логики | `Changed: Обновлён формат дат` |
| **Fixed** | Исправления багов | `Fixed: XSS в innerHTML` |
| **Removed** | Удаление функциональности | `Removed: mock.js DB-объект` |
| **Security** | Устранение уязвимостей | `Security: bcrypt вместо SHA-256` |
